# Error Codes

For a list of micro:bit error codes:
https://support.microbit.org/support/solutions/articles/19000016969-micro-bit-error-codes

This Arduino Core also uses the `300` range of error codes for issues specific
to this codebase.
To see all the error numbers consult the `MbArduinoPanic` enum in the
`microbit_hal.h` file.
